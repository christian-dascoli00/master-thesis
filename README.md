# Master's Thesis - Ideally Exact Categories

This thesis in category theory introduces ideally exact categories, a generalization of semiabelian categories that provides a categorical framework for ideals.

This framework offers a cleaner, more general way to understand ideals and other classical algebraic notions through category theory.
