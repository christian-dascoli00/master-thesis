In order to understand the notions introduced in this thesis is important to recall some definitions and constructions. We also take this opportunity to introduce and fix some notations.

First we define some categories that will be used throughout the thesis. Let $\mathcal{A}$ be a category, we defines the following categories.

\begin{itemize}
    \item The \textbf{slice category}: given an object $B$ in a category $\mathcal{A}$, we call $(\mathcal{A} \downarrow B)$ the category of objects over $E$, we denote an object by $(A, \alpha:A \to B)$. A morphism between two objects $(A, \alpha)$ and $(A', \alpha')$ is a morphism $f: A \to A'$ such that $\alpha' f = \alpha$.

\end{itemize}

We recall the following definitions.

\begin{mainbox}{}
    \begin{defi}
        A A finitely complete category $\mathcal{A}$ is said to be \textbf{regular} if
        \begin{itemize}
            \item Every morphism in $\mathcal{A}$ admits an (regular epi, mono) factorization;
            \item Regular epis in $\mathcal{A}$ are pullback stable.
        \end{itemize}
    \end{defi}
\end{mainbox}

\begin{mainbox}{}
    \begin{defi}
        A category $\mathcal{A}$ is said to be \textbf{exact} if
        \begin{itemize}
            \item It is regular;
            \item Any equivalence relation is the kernel pair of some arrow.
        \end{itemize}
    \end{defi}
\end{mainbox}

\begin{mainbox}{}
    \begin{defi}
        A finitely complete category $\mathcal{A}$ is said to be \textbf{protomodular} if for every morphism $f: A \to B$ in $\mathcal{A}$, the change-of-base functor $f^*: \mathrm{Pt}(B) \to \mathrm{Pt}(A)$ is conservative.
    \end{defi}
\end{mainbox}

We conclude recalling the following.

\begin{mainbox}{}
    \begin{defi}
        A category finitely complete category $\mathcal{A}$ is \textbf{Mal'tsev} if every internal reflexive relation in $\mathcal{A}$ is an equivalence relation.
    \end{defi}
\end{mainbox}

\begin{mainbox}{}
    \begin{defi}
        A category $\mathcal{A}$ is said to be \textbf{semiabelian} if
        \begin{itemize}
            \item It is pointed;
            \item It is exact;
            \item It is protomodular;
            \item It has binary coproducts.
        \end{itemize}
    \end{defi}
\end{mainbox}
